# Who's Adrien and What's He Building? 🤖📊

Hello there!👋🏽 I build automation and LLM tools with Claude: messy recurring processes (money, mail, a wedding) turned into small systems where each piece has one owner, only what must run is scheduled, and failures show up where someone will read them.
